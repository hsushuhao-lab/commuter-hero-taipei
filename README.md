## 🎮 操作說明

| 操作功能 | 鍵盤按鍵 | 手機虛擬觸控 | 說明 |
| :--- | :--- | :--- | :--- |
| **移動** | `A` / `D` 或 `←` / `→` | 左側 D-Pad `◀` / `▶` 或 搖桿 | 靈敏平移，支援多點觸控與持續長按不中斷 |
| **跳躍** | `Space` / `W` / `↑` | 右側圓形按鈕 `跳躍` | 支援 100ms 郊狼時間與 150ms 預先快取 |
| **衝刺 (Dash)** | `Shift` / `L` | 右側按鈕 `⚡衝刺` | 地面與空中高速位移，閃避敵彈 (CD 2.0s) |
| **專屬小招** | `S` 或 `J` | 右側按鈕 `小招` | 物理實體判定、折傘反彈敵彈與鍋氣擊退 |
| **Anime 大招** | `F` 或 `K` | 右側按鈕 `大招` | 15 金幣永久解鎖，前搖分鏡特寫、無敵位移與範圍轟炸 |
| **暫停選單** | `ESC` / `P` | 畫面右上角 `⏸️` | 暫停遊戲，可繼續、重新開始或返回主畫面 |
| **企劃風格聖經** | `Tab` 或 `F1` | 右上方 `TAB 設定` | 即時開啟 13-Sheet 風格聖經（含 08~12 新圖冊） |

## ⏱️ 通關打卡評價系統

- **Rank S (準時傳說)**：剩餘時間 ≥ 40 秒 + 墜崖失誤 ≤ 1 次。
- **Rank A (卓越通勤)**：剩餘時間 ≥ 20 秒 + 金幣 ≥ 30 + 成功通關打卡。
- **Rank B (驚險達陣)**：剩餘時間 > 0 秒，成功擊敗 Boss 並在 08:00 前抵達打卡機。
- **Rank D (上班遲到)**：時限耗盡（剩餘時間 0 秒，08:00:00 超時）或體力歸零。
