## 🌟 遊戲核心特色與重大升級 (v9.5.0)

1. **三角色招式「玩法、判定、動畫」真正差異化**：
   - **禹志晨**：Parry / Dash / Corridor。雨傘風壓斬瞬時前方扇形 melee 判定 (210px, 95°, 58 dmg, CD 0.32s)，前方 230px 偏轉敵彈並反擊 260px 風刃；大招 760px 貫穿風壓走廊。
   - **夏奇拉**：Ranged Splash / Sustain。蛋能雙彈真正遠距上下分離 (600px 射程, 90px splash, 18 splash dmg, CD 0.42s)，嚴格無近戰判定；大招 500px 固定戰區 Oeuf Mayo 蛋雨並回復 30 HP。
   - **珊卓澎**：Melee Combo / Knockback。二段連段上菜 (一段 150px 110° arc, 72 dmg, 520px knockback；0.32s 內接二段翻鍋追擊 290px 地面衝擊波 48 dmg)；大招 350px 核心吸附料理風暴。

2. **大招角色專屬五段式前搖**：
   - `INPUT → CUT-IN → WORLD WIND-UP → RELEASE → RECOVERY`。
   - Wind-up 期間角色移動鎖定、50% 傷害減免、HUD 標示 `ULT WIND-UP`，釋放瞬間進入真正無敵。

3. **魔王真正二階段變身與極限難度**：
   - Phase 1 HP 2400 → 2.8s 無敵變身盛開動畫 → Phase 2 HP 3200。
   - 溢位傷害不滲透，60 金幣僅提供共振狂暴強化 (resonanceEnraged)，不跳過 Phase 1。
   - Phase 2 招式均具備清晰 Telegraph 預警與可學習安全解（死神鐮刀 0.45s 射線+0.55s 回旋、旋刺龍卷 0.60s 預警圈、暗影瘴氣 0.55s 地面圈、捕蠅草 0.45s 警示角、花瓣雨 36° 安全扇區）。

4. **懸崖路段與平台密度重整**：
   - 一般道路移除連續平地，加入 6 個真正懸崖 (140~210px，全數符合安全起跳與著陸距離)。
   - 懸浮平台密度降低 41.7% (每場景 12 -> 7)，並加入 500~700px 地面重整區 (Ground Reset Zones)。
   - 掉崖觸發 Fall Recovery（-18 HP, -1.0s 通勤扣時，安全檢查點重生並獲 1.0s 無敵，無軟卡死）。
   - Boss Arena (14,800~16,550) 與醫院大廳 (16,500~18,000) 維持 100% 平整無斷崖。

5. **音樂三曲原則 (Three-Theme Rule)**：
   - 象山站至松德前庭全程單一 `commute_theme`（徹底消除途中突兀換曲）。
   - Boss 戰全場單一 `boss_theme`，Phase 2 透過 `audio.setBossIntensity(2)` 疊加節奏音軌，不重啟換歌。
   - 擊敗 Boss 後無縫淡入 `victory_theme`。

6. **三夥伴並肩入場與逐一打卡歡呼**：
   - Boss 擊破後，未被選中的兩位夥伴從左方加速奔馳入場會合。
   - 三人以箭頭隊形並肩衝入松德醫院大廳。
   - 打卡機前逐一打卡（1/3 -> 2/3 -> 3/3 打卡成功），打卡機實機顯示 `3 / 3 PUNCHED`。
   - 三人擺出專屬勝利姿勢，頭頂浮現互開玩笑打氣之對話氣泡與紙花歡呼。

## ⏱️ 通關打卡評價系統

- **Rank S (準時傳說)**：剩餘時間 ≥ 35 秒 + 金幣 ≥ 45 (達成共振 II) + 體力 ≥ 50 HP。
- **Rank A (卓越通勤)**：剩餘時間 ≥ 20 秒 + 金幣 ≥ 30 + 成功通關打卡。
- **Rank B (驚險達陣)**：剩餘時間 > 0 秒，成功擊敗 Boss 並在 08:00 前抵達打卡機。
- **Rank D (上班遲到)**：時限耗盡（剩餘時間 0 秒，08:00:00 超時）或體力歸零。
