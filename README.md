# 《08點上班大作戰：通勤英雄篇》
## —— 象山晨衝・奔向松德 (v8.0.0 Commercial Release) ——

一款結合台北在地晨間地景與日系魔法少女奇幻花系怪獸的高完成度 2D 橫向卷軸跑酷動作遊戲。

---

## 🌟 遊戲核心特色與重大里程碑

1. **遊戲內 Q 版人物徹底商業級重製**：
   - 告別幾何拼圖原型，全面採用 **1.8 頭身高解析抗鋸齒 Chibi 動畫**。
   - 禹志晨、夏奇拉、珊卓澎三位英雄具備專屬臉部五官、髮型剪影、細框眼鏡、服飾配件與專屬武器。
   - 每位角色擁有 32-frame 完整動畫狀態機（待機、跑步、起跳、滯空、下落、著地、受擊、小招、大招、勝利姿勢）。

2. **雙軌美術設計（主畫面寫實 vs 遊戲內 Chibi）**：
   - 主畫面保留高精緻寫實插畫，角色選擇頁提供「寫實立繪 × 動態 Q 版預覽」即時對比。

3. **零外部依賴（Zero Dependency）與純離線啟動**：
   - 最終交付單一 `index.html`，本機雙擊即可遊玩。
   - 無需 npm、無需 dev server、不加載 Tailwind CDN、Google Fonts 或外部音效圖片網址。
   - Web Audio API 100% 程式即時合成 4 首完整 BGM 與豐富音效庫。

4. **嚴格一致的遊戲數值規範**：
   - **120 秒** 上班打卡倒數（07:58:00 ～ 08:00:00）。
   - **15 枚金幣** 永久解鎖大招，解鎖後無限施放（不扣金幣），僅受角色自身冷卻時間限制。
   - **24×10px Feet Sensor** 平台頂面碰撞、**100ms Coyote Time**、**150ms Jump Buffer**、**60ms Hitstop**。

5. **七大花系怪獸與 1400px 巨花王決戰場**：
   - 7 隻晨間花系小怪皆使用 Sheet 3 專屬美術，並具備 **0.4 秒（25-frame）專屬 Telegraph 預警系統**。
   - 決戰魔王「夢影巨花王」擁有專屬 Phase 1 與 Phase 2 狂暴盛開態美術。
   - 決戰場為 **1400px 連續、100% 平整無洞地板**，魔王嚴格限定於戰場邊界內，絕無掉落出界漏洞。

## 🏃 三位通勤英雄指南

1. **禹志晨（風之通勤者・準時守護者）**：
   - **小招【雨傘風壓斬】**（冷卻 2.2s）：揮動抗風折傘，近戰重擊並發射青藍弧形風刃，可抵消前方敵彈。
   - **大招【準時衝刺・逆風傘幕】**（冷卻 9.0s）：Anime 切入特寫，高速穿透衝刺並釋放 7 道大型風刃與金色雷光，1.8 秒全無敵並消弭敵彈。

2. **夏奇拉（元氣甜心・美乃滋召喚師）**：
   - **小招【美乃滋噴射・蛋能彈】**（冷卻 1.8s）：連發兩枚半熟蛋能量彈，命中爆散出金色美乃滋濺射，射程三人中最遠。
   - **大招【元氣蛋浪・Oeuf Mayo 星雨】**（冷卻 10.0s）：星環展開，傾瀉漫天半熟蛋與流星光帶，回復 30 HP 並獲得 3.5 秒元氣護盾。

3. **珊卓澎（熱血主廚・平底鍋戰神）**：
   - **小招【爆炒上菜・鐵鍋重擊】**（冷卻 2.5s）：鑄鐵平底鍋猛力橫掃，炸裂出番茄與青花菜火花，產生 420 像素的超強擊退力。
   - **大招【主廚旋風鍋・海鷗料理風暴】**（冷卻 8.5s）：雙手握鍋旋起料理龍捲，釋放 14 道火炎旋轉鍋氣向四周爆發，先牽引再震退全場敵群。

1. **象山站 2 號出口**（0 ~ 1200 px）：晨光灑落，象山出入口與遠方 101。
2. **信義路 150 巷永和豆漿**（1200 ~ 2400 px）：市井朝氣、早點招牌、晨間水氣。
3. **雨中虎林公園**（2400 ~ 3600 px）：無縫過渡雨粒子與霧氣，冷色調氛圍，專屬雨天 BGM。

6. **夢境巨花王 Arena**（5800 ~ 7200 px）：1400px 平整決戰花海，Phase 1 & Phase 2 史詩對決！
